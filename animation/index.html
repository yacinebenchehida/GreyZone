THE POPULATION GREY ZONE

Genetic evidence
can lag behind life.

After a split, chance changes allele frequencies independently on each side. This is genetic drift. In large populations, those changes are often small, so a genetic study can struggle to detect the separation.

The grey zone depends on population sizes, gene flow, time, and the study’s sample size and markers. There is no universal generation when it ends.

A little more about the model

This draft uses two neutral diploid Wright–Fisher populations with constant sizes and unlinked biallelic markers. Their sizes add to the ancestral total, and both start with exactly matching allele frequencies. No selection, mutation, sex structure or spatial effects are included. The sharks are illustrative representatives, not a biological model of shark reproduction or behaviour.

Migration is the proportion m of each receiving population’s gene pool replaced per generation, with 0 ≤ m < 1. Both populations use the same m. Before drift, frequencies become (1 − m)p₁ + mp₂ in the west, and (1 − m)p₂ + mp₁ in the east. Expected migrant contributions are mNe for each receiving population, so they can differ when population sizes differ. The few animated crossings illustrate exchange intensity; they are not a migrant census.

FST is Hudson’s ratio of summed diversities. Samples use independent gene-copy draws and an approximate multilocus Pearson chi-square test at α = 0.05. Rare alleles and small samples can affect calibration. Each Run uses fresh random seeds for 80 independent histories. They advance along with the live clock; a new study sample in each history estimates detection power at each generation. The first checked generation with at least 80% detection is displayed as the large central generation number, and estimation continues afterwards. The curve is pointwise power, not cumulative detection. Pause freezes the live generations, sharks, power calculation and displayed results. Resume continues the same histories; +1 generation advances one generation while keeping playback paused.

“Show SNPs” displays one split-colour dot per marker, up to ten representative SNPs. Each half is one gene copy: matching halves are homozygous; different colours are heterozygous. At each marker, the allele fixed in the western basin is shown in turquoise, and its alternative in coral, using the same mapping in both basins. The colours are oriented when western fixation occurs; that orientation is retained if variation returns, until a later western fixation. Before western fixation the starting convention is used. If both basins fix the same allele, that marker is grey on both sides. The raw genotypes and original allele-A frequencies are unchanged by this display convention. The dots use stable gene-copy ranks within a run, so unchanged allele frequencies keep the same display rather than reshuffling colours each generation. They are frequency illustrations, not individual pedigrees. Significance does not freeze evolution. Fixed genotypes stay fixed; the colours use the western-reference convention and shared-fixation grey described above. FST near 1 indicates little variation within populations; some fixed SNPs can still carry the same allele on both sides, while others fix opposite alleles. The dots follow the model allele frequencies at each generation update, rounded to the displayed headcount. The statistical test always uses all selected markers. Body colour does not encode genetic identity or adaptation.

All calculations run in your browser. The power analysis runs separately so the animals can keep swimming. This is an educational prototype, not validated research software.
