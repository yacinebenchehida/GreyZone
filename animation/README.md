# GreyZone animation

## [▶ Open GreyZone](https://yacinebenchehida.github.io/GreyZone/)

Raise the barrier, press **Play**, then **Take a genetic sample**. Hammerhead sharks swim freely through the main scene, using the earlier fish’s travelling body wave and smooth steering. The **Animal** menu also offers the classic grey shark, without restarting the experiment. You can change population sizes, the split ratio, migration, sample size and marker count.

**Travel speed** controls how quickly the sharks move through the water. **Generations** controls simulation playback. **Pause** freezes both the generations and the ocean animation; **Play** resumes from the same point. Use **Shark close-up** to inspect an animal, or enable **Show SNPs** for up to ten split-colour marker dots. Each dot has two halves for its two gene copies.

The headcount is exact up to 200 individuals. Larger populations use a logarithmic display scale: 1,000 → 242 sharks; 20,000 → 320; 100,000 → 362. The scale key and basin labels explain the representation. The split ratio is retained.

Animated exchanges respond to the migration setting, the population fraction shown, and generation playback. Their rate is compressed to remain watchable. Marker colours follow the current model allele frequencies, while the statistical test continues to use every selected SNP.
