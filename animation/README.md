# GreyZone animation

## [▶ Open GreyZone](https://yacinebenchehida.github.io/GreyZone/)

The large **Time to detection** panel automatically estimates the first sampled generation with at least 80% detection power. Then raise the barrier, press **Play**, and **Take a genetic sample** to compare one study with that probability. Hammerhead sharks swim freely through the main scene, using the earlier fish’s travelling body wave and smooth steering. Normal swimming now uses the former Relaxed pace; Relaxed is slower still. The **Animal** menu also offers the classic grey shark, without restarting the experiment. You can change population sizes, the split ratio, migration, sample size and marker count.

**Travel speed** controls how quickly the sharks move through the water. **Generations** controls simulation playback. **Pause** freezes both the generations and the ocean animation; **Play** resumes from the same point. Use **Shark close-up** to inspect an animal, or enable **Show SNPs** for up to ten larger split-colour marker dots arranged in two rows. Each dot has two halves for its two gene copies.

The headcount is exact up to 200 individuals. Larger populations use a logarithmic display scale: 1,000 → 242 sharks; 20,000 → 320; 100,000 → 362; 500,000 → 404. The scale key and basin labels explain the representation. The split ratio is retained.

Animated exchanges respond to the migration setting, the population fraction shown, and generation playback. Their rate is compressed to remain watchable. Marker colours follow the current model allele frequencies, while the statistical test continues to use every selected SNP.

## [▶ Compare shark designs](https://yacinebenchehida.github.io/GreyZone/shark-study.html)

Three top-view designs (classic shark, slender shark and hammerhead), each with a free-swimming preview. [Shark design notes](SHARK_STUDY.md).

Population choices run from 10 to 500,000 in a 1–2–5 sequence. SNP choices are 1, 5, 10, 20, 50, 100, 200 and 500. Sampling is capped at the smaller population, including tiny splits.

The power result uses 80 independent histories. **Look ahead** selects 400, 2,000 or 10,000 generations. If 80% is not reached, the page states the tested horizon instead of extrapolating. The progress bar measures completed calculation work, and **Stop estimate** cancels it. The green vertical line is explicitly labelled as the current generation of the live run; it is separate from calculation progress. The channel widens modestly as Nm increases.
