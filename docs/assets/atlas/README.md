# Marine chart artwork

`marine-chart.webp` is decorative header art for GreyZone's standalone marine atlas identity, created with the built-in image generation tool on 28 October 2026 and encoded as WebP for delivery. It does not represent the simulated populations, loci or current landmass. It contains no UI or scientific labels.

Prompt: A contemporary oceanographic atlas plate in ink and soft gouache, seen directly from overhead, with sculptural rocky islands on the right, turquoise and deep blue water, nested bathymetric contours, stippled textures and narrow channels. Leave the left half pale misty celadon-white with fading outer edges for real HTML text. Marine navy, sea-glass teal, pale aqua, chalk-white rock and restrained vermilion. No animals, trees, sunsets, horizon, labels, numbers, UI, logos or watermark.

The original generated PNG is retained in the task workspace; the website uses the WebP asset.
