# Whale artwork

`whale-round.png` is the transparent source sprite used by `../whale-character.js`.
The built-in image-generation tool created it for this project, using the user's
round whale example as a design reference. The reference screenshot itself is
not included in the repository. Tail and flipper movement, mirroring, bobbing,
gene-copy overlays and blowhole splashes are rendered in the browser. The image
is decorative and does not encode genetic identity.

## Generation prompt

Use case: stylized-concept. Asset type: single isolated game character sprite for an educational whale animation. Input image: a visual reference for the very simple rounded whale design only, not a background to reproduce. Create a new complete charming little whale in this same simple rounded spirit: a big smooth plump near-spherical powder-blue body, tiny rounded flippers, two small shiny black eyes and a tiny friendly curved smile. Very simple smooth surfaces, no speckles, no throat pleats, no detail lines, no giant mouth, no long fish body. Short slender tail stock gracefully curves UP on its RIGHT side to a clearly notched pair of broad rounded blue whale flukes. Whale facing toward the LEFT in a slightly elevated three-quarter FRONT view, so both eyes and the smile are visible; closest eye on the front right of the round head, smaller farther eye near the left silhouette. Small dark oval blowhole clearly visible on top of the rounded crown. Very subtle pink cheeks. Softly shaded volume, polished adorable 3D toy character with gentle highlights, clean silhouette and no heavy outlines. Head/body is almost a ball, roughly 70% of total width. FULL complete whale including both tiny flippers and the entire short upward-curving tail with both flukes. Composition horizontal, whole animal centered with plenty of transparent margin around every appendage. True transparent background, no water, no waves, no spout, no droplets, no ground, no scenery, no shadow, no text or watermark. The splash will be animated separately in code. This should be extremely simple and cute like the reference, not the earlier long elaborate realistic baleen whale.
