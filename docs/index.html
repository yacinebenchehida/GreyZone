THE POPULATION GREY ZONE

After a split, chance changes allele frequencies independently on each side. This is genetic drift. In large populations, those changes are often small, so a genetic study can struggle to detect the separation.

The grey zone depends on population sizes, gene flow, time, and the study’s sample size and markers. There is no universal generation when it ends.

A little more about the model

This simulation uses two neutral diploid Wright–Fisher populations with constant sizes and unlinked biallelic markers. Their sizes add to the ancestral total, and both start with exactly matching allele frequencies. No selection, mutation, sex structure or spatial effects are included. The animals represent the simulated populations. Animal selection changes their appearance; the same neutral population model is used for every choice.

Migration is the proportion m of each receiving population’s gene pool replaced per generation, with 0 ≤ m < 1. Both populations use the same m. Before drift, frequencies become (1 − m)p₁ + mp₂ in the west, and (1 − m)p₂ + mp₁ in the east. Expected migrant contributions are mNe for each receiving population, so they can differ when population sizes differ. The few animated crossings illustrate exchange intensity; they are not a migrant census.

FST is Hudson’s ratio of summed diversities. Samples use independent gene-copy draws and an approximate multilocus Pearson chi-square test at α = 0.05. Rare alleles and small samples can affect calibration. Each Run generates one live population history. At every generation, 1,000 independent study datasets are sampled from that exact population pair, using the selected individuals per basin and all selected SNPs. Each dataset supplies a sampled FST and a chi-square test. The fraction of significant studies estimates power for the populations you see. The first generation with at least 80% detection is displayed as the central generation number. Evolution continues after that crossing, until you pause it or all markers are stably fixed. With no migration, fixation within both basins is stable; with migration, opposite fixation can be temporary, so automatic completion requires shared fixation at every marker. There is no fixed generation cutoff. Pause freezes generations, sharks, water and study calculation. Switching tabs does not pause the run, although browsers may throttle background computation.

“Show SNPs” displays up to ten diploid SNPs. Gold indicates a locus still segregating within at least one basin: empty = 0 copies of allele A (B/B), half-filled = 1 (A/B), filled = 2 (A/A). Shark close-up shows the same genotypes as readable numbers, labelled with the original SNP and dot indices. Grey indicates the same allele fixed in both basins; turquoise in the west and coral in the east indicate different alleles fixed. All SNPs are listed below with paired allele-A frequency bars and an optional segregating-only filter. Colours change when the marker state changes. The actual genotypes and original allele-A frequencies are unchanged. The dots use stable gene-copy ranks within a run, so unchanged allele frequencies keep the same display rather than reshuffling colours each generation. They are frequency illustrations, not individual pedigrees. Significance does not freeze evolution. Fixed genotypes stay fixed unless an allele is reintroduced; grey always means shared fixation, while light gold/orange means variation remains within at least one basin. FST near 1 indicates little variation within populations; some fixed SNPs can still carry the same allele on both sides, while others fix opposite alleles. The dots follow the model allele frequencies at each generation update, rounded to the displayed headcount. The statistical test always uses all selected markers. Body colour does not encode genetic identity or adaptation.

All calculations run in your browser. The power analysis runs separately so the animals can keep swimming.
